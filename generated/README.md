# Genererade filer

Bearbetade data, exportunderlag och detaljerade lokala rapporter läggs i en underkatalog per experiment, exempelvis `generated/001-inventory/`.

Allt innehåll utom denna README ignoreras av Git. Beskriv i experimentrapporten hur resultatet återskapas. Små granskade sammanfattningar kan versionshanteras i `experiments/`.
