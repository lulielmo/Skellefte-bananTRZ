# Lokala källdata

Lägg kopior av rådata här. Allt innehåll utom denna README ignoreras av Git.

Behåll originalen oförändrade. Registrera källa, villkor, referenssystem och kontrollsumma i `docs/DATA_SOURCES.md`. Ange hur materialet kan hämtas eller återställas; en lokal filplats räcker inte för reproducerbarhet.
