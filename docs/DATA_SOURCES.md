# Datakällsregister

Inga datakällor har ännu inventerats eller verifierats. DEM, kartor, ortofoto, spårvektorer och historiskt material är kategorier att undersöka.

För varje faktiskt använt underlag, registrera:

| Fält | Uppgift |
| --- | --- |
| ID och namn | Stabilt käll-ID och beskrivning |
| Utgivare och URL | Ursprung, produktsida och eventuell nedladdningsadress |
| Hämtat | Datum, version och filnamn |
| Täckning | Område samt tidpunkt som materialet representerar |
| Format och upplösning | Filformat, pixelstorlek eller geometri |
| Horisontell referens | CRS/EPSG eller WKT, axelordning och enhet |
| Vertikal referens | Höjdsystem, enhet och hur uppgiften verifierats |
| Villkor | Licens, attribution och eventuella begränsningar |
| Lokal placering | Projektrelativ sökväg, utan privata användarsökvägar |
| Kontrollsumma | Exempelvis SHA-256 för reproducerbarhet |
| Kvalitet | Kända brister, osäkerheter och utförda kontroller |
| Används i | Länkar till experiment |

Markera okända uppgifter som **Okänt**, och håll uppgifter från en fil åtskilda från antaganden om filen.
